# Flappy Bird Clone

**Project No.: 57**

This is a simple Flappy Bird-style game made with Python and Pygame. The bird falls because of gravity. Press SPACE to move it upward and try to pass through the gaps between the pipes.

## Requirements
- Python 3
- Pygame

## How to run
1. Open a terminal in this folder.
2. Install Pygame: `python -m pip install pygame`
3. Start the game: `python one.py`

## Controls
- **SPACE** — move the bird upward
- **R** — restart after Game Over
- **ESC** — quit the game

## Main features
- Gravity is applied to the bird on every frame.
- Pipes appear with a random gap and move from right to left.
- The score increases when the bird passes a pipe.
- The game checks collisions with pipes and the top and bottom edges.
- The game can be restarted after Game Over.
